# SkillWatch AI Frontend

Phase 2.6-2.8 uses a lightweight browser UI served by FastAPI.

Features:
- Laptop/USB camera selection by camera index
- RTSP/IP/CCTV URL input
- MP4/video upload
- Camera ID and room configuration
- Connect/disconnect controls
- Live MJPEG preview
- Camera status metadata

Open http://127.0.0.1:8000/ after starting the backend.
